# Security policy

## Supported version

Security fixes target the latest version on the project's default branch. Until a release policy is published, users should use the latest reviewed source and dependencies.

## Report a vulnerability

Please report suspected vulnerabilities privately to the BVDU Projects repository maintainers using GitHub's **Security → Advisories → Report a vulnerability** flow, if enabled for the repository. If private advisories are unavailable, contact the repository owners through the BVDU Projects organization before sharing technical details publicly. Do not attach malware samples, private keys, passwords, or personal files to a public issue.

Include the affected version/commit, platform and Python version, concise reproduction steps using harmless fixtures, expected and observed behavior, and any suggested mitigation. Please allow maintainers time to investigate and coordinate a fix before public disclosure.

## Project security boundaries

SecQuery is an on-demand scanner and must not be treated as a replacement for an active operating-system antivirus. See the limits and privacy notes in [README.md](README.md) and [USAGE_GUIDE.md](USAGE_GUIDE.md). No report guarantees that a file is safe.
